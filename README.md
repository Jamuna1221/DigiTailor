DigiTailor – AI-Powered Custom Fashion Platform

DigiTailor is a full-stack web platform designed to modernize custom tailoring services by enabling customers to explore designs, customize outfits, and place orders digitally. The platform focuses on enhancing user experience, personalization, and efficient order management through real-time interactions and intelligent features.

🚀 Features

🛍️ Design Catalog Browsing – Explore blouse and dress design collections

🎨 Design Customization Tool – Mix and preview design elements such as sleeves and neck patterns with real-time editing

📤 Custom Design Uploads – Customers can upload reference designs with enquiries

🤖 AI-Powered Chatbot – Provides automated customer assistance and basic query handling

💬 Live Chat Support – Real-time communication between customers and admin

💳 UPI QR-Based Payments – Simple and secure payment workflow

🖼️ Gallery with Reviews – Display completed works and customer feedback

⚡ Urgent Order Mode – Priority handling for time-sensitive orders

📊 Admin Dashboard with Analytics – View orders, revenue, and loyal customer metrics

🔔 WhatsApp Notifications – Order status updates and alerts
